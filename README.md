🍇 Detección de Enfermedades en Hojas de Uva
=============

### 🌱Introducción
                
----

La salud de un cultivo es fundamental para la producción de su producto. Este proyecto desarrolla un sistema basado en redes neuronales profundas para la detección de enfermedades en hojas de uva mediante imágenes. Aproveché la plataforma Roboflow para el preprocesamiento de datos y comparamos múltiples arquitecturas de aprendizaje profundo para encontrar la más efectiva.

### 🧠 Modelos Probados
                
----

🔍 He evaluado diferentes arquitecturas de redes neuronales:

- **AlexNet:** Una de las primeras redes neuronales profundas para clasificación.
- **Inception V3:** Equilibrio entre precisión y eficiencia computacional.
- **MobileNet:** Optimizado para dispositivos con recursos limitados.
- **ResNet 50:** Uso de conexiones residuales para entrenamientos profundos.
- **VGG16:** Arquitectura probada para extracción de características.
- **EfficientNet:** Modelo avanzado con una excelente relación entre precisión y eficiencia computacional.

### 📌 Conclusión
Tras evaluar múltiples arquitecturas de redes neuronales profundas, se identificó que Resnet50 y AlexNet destacaron por su capacidad de clasificación precisa y su eficiencia computacional.

En futuras mejoras, se podría explorar el uso de técnicas de aumento de datos y optimización de hiperparámetros para mejorar aún más la precisión de los modelos sin comprometer la velocidad de inferencia.
